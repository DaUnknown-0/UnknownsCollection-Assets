# UnknownsCollection-Assets

Large pictures and sounds for **Unknown's Collection**: the animated button icons, the custom hats, the pictures of the
Void eject scene, the music (werewolf form, pelican hunt, reactor) and the longer sound effects.

They are not shipped inside `UnknownsCollection.dll`. The mod downloads them automatically into `BepInEx/uc-assets`
and checks every file against the size and SHA-256 in its built-in catalog: at every start, and again whenever a file
in that folder is changed, deleted or replaced. Missing or wrong files are downloaded again; files that are not in the
catalog of the running build are deleted from that folder. `catalog.json` lists the same data for reference.

Without the download the mod keeps working: buttons show their still icon, a hat that is not on disk yet sits out
that session, the Void eject keeps the plain screen and the outsourced sounds stay silent.

- `files/anim.*.png`: 16-frame loops of the button icons.
- `files/hats.*.png`: the hats (TOR reads the main, back and climb pictures from `TheOtherHats`, the mod writes them
  there once they are downloaded).
- `files/task_eject_*`: Void eject scene.
- `files/*.ogg`: music and longer sound effects (Ogg Vorbis).
- Each tag (`v1`, `v2`, ...) is one set of files; a build of the mod always reads from the tag in its catalog.

Generated by `tools/build_assets_repo.py` in the UnknownsCollection repository. Licensed under GPL-3.0-or-later like
the mod.
